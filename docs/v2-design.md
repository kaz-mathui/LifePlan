# LifePlan v2.0 設計ドキュメント

**作成日:** 2026-05-31
**ステータス:** 設計確定段階(実装着手前)

---

## ビジョン

> **全情報を1-3ヶ月かけてミッション形式で入力 → 完成後は自分の人生の精密予測ダッシュボード**

「あれば便利」止まりだった既存サービスを超え、**一度作れば10年使える"自分の財産"** となるアプリ。

---

## 3つの設計原則

### 1. モバイルファースト
- 1日3分でできる入力体験
- 通勤・ベッドの中・トイレで進められる
- スマホ縦持ち最適化、PCはレスポンシブで対応

### 2. ミッション形式
- 「今日のミッション3問」を毎日提示
- 全186問を1-3ヶ月で完成
- 強制せず、自分のペースで

### 3. プログレッシブ
- 必須20問完了 → ベース予測表示
- 推奨50問完了 → 詳細予測
- 全問完了 → 精密予測ダッシュボード
- 入力途中でも価値が出る

## ミッションロジック

### 表示優先度

```typescript
score = priorityWeight + impactWeight + difficultyWeight

priorityWeight: essential=100, recommended=50, optional=10
impactWeight:   high=30, medium=20, low=10
difficultyWeight: easy=15, medium=10, hard=0
```

`easy + essential + high` (合計145) のものから優先表示。

### 表示数

- 1日3問デフォルト
- 「もう少しやる」で+3問追加(計6問)
- 強制感を出さず、自分のペースで

### 依存質問

`dependsOn` で他の回答に依存する質問は、条件が満たされるまで自動非表示。
例: `sp_age` (配偶者年齢) は `sp_status === 'married'|'cohab'` の時だけ表示。

## データモデル

### 質問定義 (`questions.ts`)
- 186問の静的定義
- カテゴリ・優先度・依存関係を保持

### 回答保存 (Firestore)
```
plans/{planId}/answers/{questionKey} = {
  value: any,
  answeredAt: timestamp,
  source: 'manual' | 'mf_import' | 'estimate'
}
```

### 既存型との互換

既存 `SimulationInputData` は廃止せず:
- v1の入力フォームは「シンプル版」として残す
- v2は新規UIで186問対応
- どちらも同じFirestoreの `data` フィールドに保存(キー体系統一)
- マイグレーション関数で v1 → v2 変換可能

## 大方針（プロダクトビジョン）

> **資産管理を簡単に可視化、将来の見通し、アクションプランが見える！**

## ヒアリングの結論

5ペルソナ（MFヘビー / 子育て住宅検討 / 家計初心者 / FP批評家 / 多忙エンジニア）の合意点:

1. **アクションプラン欠落**（5/5・critical）— グラフ止まり。「で、何をすべき？」に答えない。離脱理由の第1位。
2. **アンロック前に価値が見えない**（4/5・critical）— コア12問の先に何があるか不明。117問の心理的壁。
3. **判定シグナルがない**（3/5・critical）— 「安全？危ない？」の🟢🟡🔴がない。
4. **前提条件ブラックボックス**（2/5・major）— リターン率/インフレ/年金前提が非開示で信用されない。
5. **v1/v2の使い分け不明**（3/5・major）。
6. **MF二度手間**（1/5だが対象層の核心）— MFImport は実装済み。導線が死んでいるだけ。

**メタ発見: WhatIf / 戦略ボード / Monte Carlo / MFインポートは実装済みなのに初回体験で不可視。**
→ 主戦場は「価値の前出し」と「判定・アクションの言語化レイヤー」。

## Phase 2: 次回以降（優先順）

1. **シナリオ横並び比較表**（FP批評家・MFヘビー）— 複数プランの60/65歳資産を表で比較。PlanSelector 基盤あり。
2. **差分更新フロー**（FP批評家・子育て）—「前回から変わったことは？」3ヶ月ごと再診断。回答に更新日時は保存済み。
3. **目標設定 + ギャップ表示**（初心者）—「目標3,000万 vs 予測2,200万 / 必要月貯蓄X万」。
4. **v1/v2 の役割明確化 or v1 廃止**（3人）— v2 をデフォルトに、v1 は「クイック診断」に再定義。
5. **夫婦共有ビュー**（子育て）— バイラル成長仮説とも一致。認証・権限設計が必要で重い。
6. **ログイン前LP**（初心者）— アプリ価値の3枚説明 + デモスクショ。
7. **仮予測の既定値見直し**（2026-07-05検証で発見）— 回答0問の既定値だと「快晴・成功確率100%・65歳8,531万」と楽観的すぎ、初心者の「ヤバさを知りたい」動機に繋がらない。同世代中央値ベースへの調整 or 仮予測時の判定文言切り替えを検討。
8. **匿名ユーザーの plans 取得で Firestore permission エラー**（既存事象・console error）— PlanSelector が匿名時に権限エラーを吐く。rules か fetch ガードの修正。

## 判断メモ

- 収益仮説: 「判定 + アクション」があれば月300〜1,000円の支払い意向（3/5人）。無ければ全員0円。
- 競合ポジション: MF ME=現在地、銀行診断=単発。**「続けて使う未来予測 + 行動提案」が空白地帯。**

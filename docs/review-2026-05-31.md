## ミッション選出ロジック修正

### Before (バグあり加算)
```typescript
s += { essential: 100, recommended: 50, optional: 10 }[q.priority];
s += { high: 30, medium: 20, low: 10 }[q.impact];
s += { easy: 15, medium: 10, hard: 0 }[q.difficulty];
```
**問題**: essential が尽きた後、optional×low×easy(35) が optional×high×hard(20) を上回り、重要だが面倒な質問が永遠に出ない。

### After (乗算 + 多様化)
```typescript
const priorityScore = { essential: 1000, recommended: 100, optional: 10 }[q.priority];
const impactMultiplier = { high: 3, medium: 2, low: 1 }[q.impact];
const easeBonus = { easy: 5, medium: 3, hard: 1 }[q.difficulty];
return priorityScore * impactMultiplier + easeBonus;
```
加えて「同カテゴリ連続を避ける」多様化フィルタを追加。
